# 7. CORE PHILOSOPHY

COALA SwarmOps is based on several fundamental principles.

---

## 7.1 Self-Hosted First

The platform prioritizes:
- local execution
- operational independence
- controllable infrastructure
- low-cost execution
- privacy
- infrastructure ownership

Cloud models are fallback layers, not primary dependencies.

---

## 7.2 Cost-Aware Routing

The system is specifically designed to:
- minimize unnecessary token usage
- optimize model selection
- route tasks based on complexity
- escalate reasoning only when needed

---

## 7.3 Adaptive Tier Escalation

The orchestration system follows a tier model.

### Tier 1
Low-cost execution

Examples:
- DeepSeek
- Qwen
- Kimi

Purpose:
- fast execution
- low token cost
- operational tasks

---

### Tier 2
Balanced execution

Purpose:
- moderate reasoning
- code generation
- infrastructure planning

---

### Tier 3
Advanced reasoning

Examples:
- Claude
- GPT-class reasoning systems

Purpose:
- critical reasoning
- architectural validation
- advanced orchestration

Escalation only occurs when lower tiers fail or confidence thresholds are not met.

---

## 7.4 Specification Driven Development (SDD)

COALA SwarmOps strongly emphasizes:
- structured development
- controlled context
- reduced hallucinations
- token optimization
- workflow consistency

The project intentionally avoids chaotic AI prompting patterns.

---

## 7.5 Operational AI

The project focuses on:

- engineering execution
- infrastructure orchestration
- deployment automation
- repository intelligence
- operational assistance
- software architecture
- DevOps workflows

Not generic chat interactions.
